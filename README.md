# 🚀 BTech Roadmap — 4 Years to Dream Job

A beautiful, interactive web app that maps out a complete 4-year skill roadmap for B.Tech / tech students to land a high-package job.

## ✨ Features

- **3D tilt-effect cards** — move your mouse over any card
- **Floating parallax hero** — mouse moves the hero elements in 3D space  
- **Animated particle background** — subtle depth and life
- **Reveal on scroll** — sections animate in as you scroll
- **Year-by-year roadmap** covering 40+ skills across 4 phases
- **Mobile responsive** design

## 📅 Roadmap Coverage

| Year | Theme | Key Areas |
|------|-------|-----------|
| Year 1 | Foundation | Programming basics, Linux, Git, Communication |
| Year 2 | Skills & Domain | DSA, Web/ML/App Dev, Databases, DevTools |
| Year 3 | Build & Prove | Internships, Projects, Open Source, Cloud |
| Year 4 | Job Ready | Resume, System Design, Interview Prep, Offers |

## 🛠 Tech Stack

- Pure HTML5, CSS3, Vanilla JavaScript
- CSS animations & 3D transforms
- IntersectionObserver API (scroll reveals)
- Canvas API (particles)
- Google Fonts (Inter + Space Grotesk)

## 🚀 Run Locally

Just open `index.html` in your browser — no build step needed!

```bash
# Or use a local server
npx serve .
```
