## ✨ What Makes This Different

This isn't a boring list of links. It's a **visual, interactive experience** built to keep students motivated and on track.

- 🃏 **3D Tilt Cards** — every skill card tilts in 3D as your mouse moves over it
- 🖱️ **Mouse Parallax** — the hero floating cards follow your cursor in 3D space
- ✨ **Scroll Reveal** — year sections and cards animate in as you scroll
- 🌀 **Live Particle Background** — subtle animated canvas dots for depth
- 🔵 **Cursor Glow** — a soft light follows your cursor across the page
- 📱 **Fully Responsive** — works great on mobile, tablet, and desktop
- ⚡ **Zero Dependencies** — pure HTML, CSS, JS. No frameworks, no npm, no build step

## 🚀 Run Locally

```bash
# Clone the repo
git clone https://github.com/Nirvighantamrakar/btech-roadmap.git

# Open directly in browser
cd btech-roadmap
start index.html       # Windows
open index.html        # Mac
xdg-open index.html    # Linux
```

Or use a local server for best experience:

```bash
npx serve .
# Visit http://localhost:3000
```

## 🌐 Deploy on GitHub Pages (Free)

1. Go to your repo → **Settings** → **Pages**
2. Under *Branch*, select `main` → `/ (root)` → **Save**
3. Your site is live at:

```
https://Nirvighantamrakar.github.io/btech-roadmap
```
