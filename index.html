01

The Foundation Year

Think like an engineer, not just a student

Sem 1–2
💻

Programming Basics

  • C or Python as your first language
  • Loops, functions, recursion, OOP
  • Solve 50+ problems on HackerRank
  • Understand time & space complexity
Must Do
🐧

Linux & Terminal

  • Install Ubuntu / use WSL
  • File system, permissions, processes
  • Bash scripting basics
  • Git: init, add, commit, push, branch
Foundation
🧮

Math for CS

  • Discrete Math: sets, graphs, logic
  • Boolean algebra & logic gates
  • Probability basics (for ML later)
  • Big-O notation — always think in terms of it
Core
🗣️

Communication

  • Technical writing: clear emails & docs
  • English fluency (Grammarly helps)
  • Present your lab code with confidence
  • Read tech blogs: DEV.to, Medium
Soft Skill
🌐

Internet & GitHub Basics

  • How the internet works: DNS, HTTP/S, TCP/IP
  • Client–server model, what is a web server?
  • Browser dev tools — Inspect, Network tab
  • Create your GitHub profile — push your first 3 repos!
Foundation
🏁 Year 1 Goal: 3 GitHub repos live. Comfortable in the terminal. Solving daily problems. GitHub profile looks alive.
02

Skills & Specialization

Pick your domain, go deep, think in systems

Sem 3–4
⚡

DSA — Data Structures

  • Arrays, Strings, Linked Lists, Stacks, Queues
  • Trees, Graphs, Heaps, Hash Maps
  • Sorting, Searching, Divide & Conquer
  • LeetCode — target 100+ problems
Must Do
🖥️

Choose Your Domain

  • 🌐 Web Dev — HTML/CSS, JS, React
  • 📱 App Dev — Flutter or Kotlin
  • 🤖 AI/ML — Python, NumPy, scikit-learn
  • 🔒 Cybersecurity — Kali, TryHackMe
Specialize
🗄️

Databases

  • SQL: SELECT, JOIN, GROUP BY, indexes
  • PostgreSQL or MySQL setup locally
  • MongoDB intro — documents vs tables
  • Design a schema for a real use-case
Core
🔧

Dev Tools & Workflow

  • VS Code shortcuts, Vim basics
  • Git: branching, merge conflicts, PRs
  • Docker basics — images & containers
  • Postman for REST API testing
Productivity
🏗️

System Design Basics

  • What is an API? REST vs GraphQL
  • MVC architectural pattern
  • Read "Grokking System Design" (free)
  • Design a small system on paper
Thinking
🤝

Start Networking

  • Polish your LinkedIn — 500+ connections
  • Follow engineers at FAANG/Unicorns
  • Join a college coding club / ACM
  • Attend 1 hackathon this year
Career
🏁 Year 2 Goal: 2 domain projects on GitHub. 100+ LeetCode solved. Attended a hackathon. LinkedIn profile active.
03

Build & Prove

Real projects, code reviews, real internships

Sem 5–6
💼

Internships

  • Apply to 50+ companies (Internshala, LinkedIn)
  • Target startups: broader role, fast learning
  • Even unpaid = real experience & LoR
  • Ask for a Letter of Recommendation always
Must Do
🚀

Major Project

  • Production-ready app — not tutorials
  • Deploy it: Vercel, Railway, AWS free tier
  • Real auth, database, payments if possible
  • Write a killer README with screenshots
Showpiece
🔓

Open Source

  • Find "good first issue" labels on GitHub
  • GSoC / GSSoC / Hacktoberfest
  • Review others' PRs — builds credibility
  • Stars & forks = social proof
Community
☁️

Cloud & DevOps

  • AWS / GCP free tier — deploy a server
  • CI/CD pipelines with GitHub Actions
  • Kubernetes basics (k8s concepts)
  • Linux server: SSH, nginx, systemd
In-Demand
📊

Advanced Competitive Programming

  • LeetCode Medium/Hard — aim 250+ problems
  • Codeforces — reach Specialist (1200+ rating)
  • Deep dive: DP, Greedy, Graphs, Segment Trees
  • Weekly contests — consistency is everything
Top Priority
🏁 Year 3 Goal: 1 internship done. Deployed project with real users. 250+ LeetCode problems. Active open source contributions.
04

Job Ready — Final Push

Polish everything and land that offer

Sem 7–8
📝

Resume & LinkedIn

  • 1-page ATS-friendly resume (Jake's template)
  • Quantify impact — "Reduced load 40%"
  • LinkedIn: role you want, not your degree
  • 3 recommendations from seniors/mentors
Must Do
🧠

System Design (Advanced)

  • Design: URL shortener, Twitter, WhatsApp
  • Load balancers, CDNs, Redis caching
  • DB sharding, replication, CAP theorem
  • Gaurav Sen & ByteByteGo on YouTube
L4+ Interviews
🎯

Interview Prep

  • Mock interviews — Pramp, Interviewing.io
  • Company-specific LeetCode lists
  • "Tell me about yourself" — nail it cold
  • STAR method for behavioural rounds
Execution
🏢

Campus + Off-Campus

  • Register for campus placements early
  • Apply off-campus to startups in parallel
  • Referrals: message 20 engineers directly
  • AngelList, Wellfound, LinkedIn Easy Apply
Strategy
🌟

Specialization Stack

  • Go deep in 1 area: ML, DevOps, Security, etc.
  • Get a certification: AWS SAA / GCP ACE
  • Write 1 technical blog / month on Medium
  • Speak at a college tech fest or meetup
Stand Out
💡

Mindset & Wellbeing

  • Rejection is data, not failure — iterate
  • Build in public: tweet, post, share your work
  • Stay consistent: 2 hrs of coding daily > 10 hrs weekends
  • Your network is your net worth — genuinely help others
Always
🏁 Year 4 Goal: Offer in hand 🎉 — whether campus or off-campus. Resume polished. Mock interviews done. Mindset ready for the real world.
